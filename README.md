# Flervariabel kalkulus og PDE-er – matematikkhjelp.no

Lærestoffet i faget **Flervariabel kalkulus og PDE-er** på [matematikkhjelp.no/flervariabel-kalkulus/](https://matematikkhjelp.no/flervariabel-kalkulus/), på ingeniørnivå: dobbelt- og trippelintegraler, linje- og flateintegraler, vektorfelt og integralsetningene, partielle differensiallikninger og numeriske metoder (endelige differanser og endelig volum-metoden).

- `kapitler/` – én mappe per kapittel, én `.qmd`-fil per side. Hver side har `tema:` og `undertema:` øverst (temakartet er `matematikkhjelp/tema.yml` i [Plattform](https://github.com/Realfagsambassaden/Plattform)).
- `figurer/` – TikZ-figurer. `python3 figurer/lag.py` lager `bilder/figurer/*.svg`.
- Sider med `plassholder: true` er ikke skrevet ennå.

Stoffet er skrevet med egne ord og egne eksempler, med lærernes forelesningsnotater som utgangspunkt for hva som skal dekkes.

Les [AGENTS.md](AGENTS.md) og [BIDRA.md](BIDRA.md) før du bidrar. Alt på `main` publiseres automatisk.
